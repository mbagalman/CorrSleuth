# Development Docs

Internal planning, architecture, and process documents for CorrSleuth.
These are aimed at contributors and maintainers, not at analysts using
the package.

| File | What it is |
|---|---|
| [AGENTS.md](AGENTS.md) | Canonical reference for AI agents (and humans) working on CorrSleuth. Product principles, conventions, and the core demo. |
| [architecture.md](architecture.md) | Technical architecture spec — pipeline structure, data contracts, and lazy-loading boundaries. |
| [PRD.md](PRD.md) | Detailed product requirements document for v0.1. |
| [product-spec.md](product-spec.md) | Early high-level product idea summary. |
| [game-plan.md](game-plan.md) | Phased rollout plan from the early planning phase. |
| [relationship-profiler.md](relationship-profiler.md) | Original product write-up that became CorrSleuth. |
| [adoption-ticket-pack.md](adoption-ticket-pack.md) | Ticket-by-ticket roadmap (Phases 1–5) with status, completion notes, and acceptance criteria. The implementation log of how the package got from v0.1 to its current shape. |

For the user-facing docs (interpretation guide, design notes), see
[../](..).
